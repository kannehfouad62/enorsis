# B4.5 — Specialized Conversational Procurement Assistants

Adds five role-aware conversational assistants:

- Procurement Assistant
- Supplier Assistant
- Inventory Assistant
- Contract Assistant
- Executive Assistant

Architecture:
- shared assistant orchestration
- existing governed AI gateway
- existing AiCapability enum values
- Enterprise RAG semantic retrieval
- source/chunk evidence persisted on AiExecution
- role-aware assistant availability
- mandatory human control for operational decisions
- no autonomous purchase, award, payment or contract execution

The assistants deliberately reuse existing governed capabilities instead of
creating new model/provider pathways.

No Prisma migration or new npm dependency is required.
