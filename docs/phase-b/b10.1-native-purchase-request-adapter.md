# B10.1 — Native Purchase Request Adapter

B10.1 is the first governed autonomous execution adapter that creates a real
native Enorsis transactional record.

Verified native model contract:
- PurchaseRequest.status defaults to DRAFT
- requesterId is required
- requestNumber is unique within a tenant
- title and businessJustification are required
- originalCurrency, totalAmount, usdEquivalent, exchangeRateToUsd,
  exchangeRateSource and exchangeRateDate are required
- PurchaseRequestLine requires lineNumber, description, quantity,
  unitOfMeasure, unitPrice and lineTotal

B10.1 behavior:
- accepts only governed native drafts targeting PURCHASE_REQUEST
- requires the source B9.4/B9.5 adapter state to be valid
- is idempotent when a nativeReferenceId already exists
- creates exactly one native PurchaseRequest in DRAFT
- creates one initial PurchaseRequestLine from the governed execution payload
- uses USD / 1.0 FX because B9 staged values are USD-denominated
- binds the resulting Purchase Request ID and route back to the autonomous chain
- writes autonomous-native decision evidence and audit evidence

B10.1 explicitly does not:
- submit the Purchase Request
- construct approval decisions
- approve/reject the Purchase Request
- create a Purchase Order
- issue an order
- create receipts
- create invoices
- initiate payment

Native route:
`/app/requests/[id]`

Adapter workspace:
`/app/governance/autonomous-execution/native-drafts/purchase-requests`

No Prisma schema migration is required for B10.1 because it uses the existing
PurchaseRequest, PurchaseRequestLine, AutonomousNativeWorkflowDraft and
AutonomousExecutionAdapterJob models.
