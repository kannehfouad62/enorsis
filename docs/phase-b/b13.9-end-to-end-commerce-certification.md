# B13.9 — End-to-End Commerce & Transaction Lifecycle Certification

B13.9 is the final pre-UAT functional readiness certification.

Golden path:

Tenant
→ Supplier
→ Marketplace Catalog
→ Purchase Request
→ Approval
→ Purchase Order
→ Supplier Acceptance
→ Shipment
→ Goods Receipt
→ Warehouse Receiving / Putaway
→ Inventory
→ Supplier Invoice
→ Three-Way Match
→ Payment Readiness / Payment

The certification is deliberately non-destructive.

It verifies:
- application routes
- implementation module presence
- PostgreSQL persistence table presence
- commerce role definitions
- tenant-scoping signals
- audit/event infrastructure

It does not create:
- tenants
- users
- catalog items
- requests
- purchase orders
- shipments
- receipts
- inventory transactions
- invoices
- payments

Workspace:
`/app/settings/platform-readiness/end-to-end-commerce`

API:
`POST /api/platform/end-to-end-commerce-certification`

Migration:
`20260809120000_end_to_end_commerce_certification`

After B13.9 passes, testing moves to manual UAT using distinct identities for:
- Platform Super Admin
- Buyer Tenant Admin
- Requester
- Approver
- Buyer/Procurement
- Warehouse/Receiving
- Finance/AP
- Supplier Admin
- Supplier Order/Fulfillment users
