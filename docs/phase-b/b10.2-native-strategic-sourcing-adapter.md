# B10.2 — Native Strategic Sourcing Adapter

B10.2 creates a real native Enorsis SourcingEvent from an eligible governed
autonomous native draft.

Verified native SourcingEvent contract:
- eventNumber is required and tenant-unique
- type is required
- status defaults to DRAFT
- title, summary and scopeOfWork are required
- currencyCode defaults to USD
- estimatedValue is optional
- sealedResponses defaults to true
- allowMultipleRounds defaults to false
- currentRound defaults to 1

B10.2 creates:
- type: RFP
- status: DRAFT
- currency: USD
- sealedResponses: true
- allowMultipleRounds: false

B10.2 binds the native SourcingEvent ID and route back into the autonomous
execution chain and writes audit/decision evidence.

It explicitly does not:
- publish the event
- invite suppliers
- open sealed responses
- assign evaluators
- score responses
- create an award recommendation
- approve an award
- create a contract or purchase order

Native route:
`/app/sourcing/[id]`

Adapter workspace:
`/app/governance/autonomous-execution/native-drafts/sourcing`

No Prisma migration is required because B10.2 uses existing native and
autonomous-governance models.
