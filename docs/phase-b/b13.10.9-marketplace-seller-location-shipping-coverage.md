# B13.10.9 — Marketplace Seller Location & Shipping Coverage

## Purpose

Give Buyers geographic context before selecting a marketplace supplier offer.

## Seller location

Seller location is derived from existing governed organization data rather than
duplicated on every product listing.

Resolution order:

1. seller tenant's first ACTIVE operating site
   - city
   - region
   - country
2. seller tenant primary country
3. "Location not specified"

This means changes to the seller's organization/site configuration continue to
flow into marketplace presentation.

## Shipping / sales coverage

The existing `SupplierMarketplaceOffering.countriesAvailable` field is retained.

The Publish Offering page now labels it clearly as:

**Countries you sell / ship to**

Sellers may provide multiple destinations as a comma-separated list.

Examples:

- United States
- United States, Canada
- United States, Canada, United Kingdom, France

## Buyer marketplace presentation

Each product family shows:

- Seller location
- Sells / ships to

alongside the existing image gallery, descriptions, price, lead time, supplier
comparison and cart controls.

## Data model

No Prisma migration is required.

B13.10.9 reuses:
- Tenant.countryCode
- Site.city
- Site.region
- Site.countryCode
- SupplierMarketplaceOffering.countriesAvailable
