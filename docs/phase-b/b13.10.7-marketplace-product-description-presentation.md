# B13.10.7 — Marketplace Product Description Presentation

## Purpose

Improve Buyer marketplace discovery by exposing the descriptive product content
that suppliers already enter when publishing an offering.

## Marketplace Catalog behavior

Each product/service family card now displays:

- product/service name
- model number when present
- supplier-entered short description
- expandable "View full description" control
- full long description inside an expandable panel

The long description remains collapsed by default so catalogs with many products
stay compact and easy to scan.

Paragraph and line-break formatting is preserved for the full description.

## Data model

No new fields are introduced.

B13.10.7 uses the existing:
- SupplierMarketplaceOffering.shortDescription
- SupplierMarketplaceOffering.description

No Prisma migration is required.
