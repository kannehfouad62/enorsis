# B13.10.4 — Marketplace Product Media & Commerce Presentation

Adds tenant-owned marketplace product/service media using private Vercel Blob storage.

- JPG, PNG and WebP
- maximum 8 images per offering
- 8 MB maximum per image
- first uploaded image becomes primary
- add, remove and change primary image
- authenticated marketplace media proxy
- published listings may be viewed by authenticated marketplace users across tenant boundaries; hidden listing media remains tenant/platform restricted
- Amazon-style primary image and thumbnail presentation on marketplace cards
- BUYER and BUYER_SUPPLIER tenants discover published offerings across the Enorsis marketplace; SUPPLIER tenants manage their own offerings, including hidden drafts

Existing `imageRef` is retained as the primary-image compatibility reference. Binary image data is never stored in PostgreSQL.
