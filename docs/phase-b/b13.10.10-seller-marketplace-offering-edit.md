# B13.10.10 — Seller Marketplace Offering Edit

## Purpose

Allow Supplier and Buyer+Supplier tenants to maintain product/service
information after publication without deleting and recreating the listing.

## Seller workflow

Marketplace Catalog -> Manage supplier listings -> Edit offering

Route:

`/app/marketplace/catalog/[id]/edit`

## Editable fields

- offering type
- SKU / service code
- product/service name
- short description
- full description
- category / subcategory
- manufacturer
- brand
- model number
- unit of measure
- currency
- unit price
- minimum order quantity
- lead time
- availability
- countries sold/shipped to
- certifications
- search keywords
- document reference
- external URL
- marketplace visibility
- featured status

Product media is intentionally preserved and remains managed from the existing
catalog workspace.

## Tenant isolation

The edit query and update action both verify that the offering belongs to the
authenticated tenant. A seller cannot edit another seller tenant's listing.

## Auditability

Every save writes:

`supplier_marketplace.offering.update`

with before/after commercial evidence.

## Existing purchase transactions

Changing a live marketplace listing does not rewrite previously submitted
Purchase Request snapshots or issued Purchase Orders. B13.10.5 already preserves
the transaction-time marketplace price and seller metadata in immutable purchase
bindings.

No Prisma migration is required.
