# B13.10.18 — Hide Supplier Discovery for Supplier-Only Tenants

## Problem

`/app/marketplace/trust` rendered the `Supplier Discovery` navigation action
for every authorized Marketplace Trust user.

Supplier-only tenants are not authorized to access:

`/app/marketplace/suppliers`

This created a dead-end navigation experience where a Supplier user could see
and click an action that immediately returned `Access not authorized`.

## Fix

Marketplace Trust now returns the authenticated tenant's commercial persona.

The Trust page renders `Supplier Discovery` only when:

`commercialPersona !== "SUPPLIER"`

Therefore:

- SUPPLIER -> hidden
- BUYER -> visible
- BUYER_SUPPLIER -> visible
- platform/operator contexts retain the existing route behavior

The authorization guard on `/app/marketplace/suppliers` is not weakened.

## Scope

No Prisma migration is required.
No Supplier Discovery permission changes are introduced.
This is persona-aware navigation hardening only.
