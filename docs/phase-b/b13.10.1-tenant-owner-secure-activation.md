# B13.10.1 — Secure Tenant Owner Invitation & Account Activation

## Flow

PLATFORM_SUPER_ADMIN creates tenant
→ passwordless user gets TENANT_OWNER + TENANT_ADMIN membership in INVITED state
→ secure 256-bit activation token
→ purpose-namespaced SHA-256 token hash stored in existing PasswordResetToken
→ Resend email
→ /activate-account
→ existing Enorsis hashPassword() bcryptjs/12 rounds
→ emailVerified/passwordChangedAt
→ membership ACTIVE
→ token usedAt
→ audit evidence
→ login

Existing credentialed users remain ACTIVE and do not require activation.

Existing B13.10 tenants with passwordless owners can be recovered from
/app/settings/tenants/[id] using Send/Resend activation invitation.

## Environment

RESEND_API_KEY
RESEND_FROM_EMAIL (preferred) or WORKFLOW_EMAIL_FROM
NEXT_PUBLIC_APP_URL=https://www.enorsis.com (recommended)

The sender address/domain must be verified in Resend.

## Verification

1. Open the existing Buyer tenant as PLATFORM_SUPER_ADMIN.
2. Click Send activation invitation.
3. Verify email delivery.
4. Open /activate-account?token=...
5. Create a password: 12+ characters, upper/lowercase and number.
6. Verify redirect to /login?activated=1.
7. Log in as Buyer Tenant Owner.
8. Confirm /app/settings/organization resolves the Buyer tenant.
9. Reuse the activation URL; it must be rejected.
