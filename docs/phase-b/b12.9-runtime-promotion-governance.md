# B12.9 — Governed Runtime Policy Promotion & Rollback

B12.9 governs SHADOW → ENFORCED promotion and ENFORCED → SHADOW rollback.

Promotion readiness inputs:
- current adoption mode
- minimum decision count
- observed shadow divergence rate
- fallback/default rate
- clamped decision count
- denied decision count

Default promotion rules:
- adoption must be SHADOW
- at least 20 decisions
- divergence <= 20%
- fallback rate <= 25%
- no clamped policy values
- readiness score >= 80

Promotion never occurs automatically.
An authorized user must approve an eligible assessment.

Rollback monitoring:
- divergence rate
- fallback rate
- denied-decision rate
- minimum sample volume

Default rollback ceilings:
- divergence > 20%
- fallback > 25%
- denied decisions > 50%
- minimum 20 decisions before recommendation

Automatic rollback is disabled by default.
