# B12.6 — Safe Runtime Policy Consumption & Guardrails

B12.6 introduces the controlled runtime gateway for ACTIVE B12.5 learning
policies.

Runtime-supported policy type:
- CONFIDENCE_THRESHOLD

Advisory-only policy types:
- PREDICTION_RULE_REVIEW
- WORKFLOW_RECOMMENDATION_REVIEW

Resolver controls:
- only ACTIVE policy versions are considered
- unsupported policy types fall back to caller defaults
- missing/invalid numeric values fall back to caller defaults
- confidence thresholds are clamped to 0–100
- the policy ID, proposal ID and version are returned for audit evidence
- rollback is immediate because the resolver reads the currently ACTIVE
  version on every resolution

Primary APIs:
- `resolveRuntimeLearningPolicy`
- `resolveConfidenceThreshold`
- `evaluateGovernedConfidenceGate`
- `createRuntimePolicyEvidence`

Workspace:
`/app/analytics/outcome-learning/runtime-policy`

Read API:
`/api/analytics/outcome-learning/runtime-policy`

No Prisma migration is required.

B12.6 does not execute procurement actions. It provides a safe runtime policy
gateway that AI engines can use for bounded confidence gating.
