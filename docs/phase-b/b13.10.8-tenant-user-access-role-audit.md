# B13.10.8 — Tenant User Access & Role Audit

## Purpose

Provide Platform Super Admin with a non-destructive access review for all users
already provisioned in an Enorsis tenant.

## Live audit

The Platform Tenant detail page displays a live access review for every member:

- current membership status
- current assigned roles
- credential posture
- PASS / WARN / FAIL result
- detailed findings

## Audit scenarios

FAIL:
- member has no assigned tenant role
- tenant membership contains a platform-only role

WARN:
- ACTIVE membership has no configured credentials
- INVITED membership already has credentials
- supplier-only tenant has buyer/procurement roles
- buyer-only tenant has supplier-management roles

PASS:
- no current access-governance finding detected

Commercial persona mismatch findings are warnings rather than automatic failures
because an authorized administrator may intentionally create an exception.

## Evidence

"Record access audit" stores a complete snapshot in AuditEvent:

`platform.tenant.access-role.audit`

The evidence contains:
- tenant commercial persona
- users reviewed
- pass/warn/fail counts
- each user's roles and membership status
- each finding code, severity and message

## Non-destructive design

The audit never adds or removes roles automatically.

Corrections remain explicit administrative actions through B13.10.6 role
assignment controls.

No Prisma migration is required.
