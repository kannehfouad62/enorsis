# B11.1 Navigation Group Repair v3

The prior repair checked for `"Automation"` anywhere in
`enterprise-modules.ts`. Because the B11.1 module entry itself already
contained `group: "Automation"`, that check could incorrectly conclude that
the `EnterpriseModuleLink.group` type had been updated.

v3 scopes all inspection and replacement strictly to the
`EnterpriseModuleLink` declaration and its `group:` property.

No schema changes.
No Prisma migration.
No database operation.
