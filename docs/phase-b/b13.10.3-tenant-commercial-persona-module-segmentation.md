# B13.10.3 — Tenant Commercial Persona & Module Segmentation

Personas:
- BUYER
- SUPPLIER
- BUYER_SUPPLIER

Existing tenants default safely to BUYER and may be reclassified by Platform Super Admin from `/app/settings/tenants/[id]`.

Access is the intersection of tenant persona, module entitlement, user role, scope, and route authorization.

SUPPLIER tenants receive a focused supplier command center and supplier-relevant modules. Buyer-only route families are server-side guarded. BUYER tenants retain procurement functionality and cannot use supplier-portal routes. BUYER_SUPPLIER tenants can use both personas.

Persona changes are audit logged.
