# B13.2 — AI Runtime Health & Production Monitoring

B13.2 adds production monitoring for governed AI runtime behavior.

Health inputs:
- runtime decision count
- ACTIVE policy usage rate
- DEFAULT fallback rate
- denied decision rate
- clamped decision rate
- trace integrity
- ACTIVE runtime policy count
- advisory-only policy count
- latest B13.1 certification status/score
- B12.8 adoption mode

Anomaly examples:
- fallback rate above 25%
- any clamped policy values
- trace integrity below 100%
- ENFORCED runtime without clean certification
- ENFORCED runtime without an ACTIVE confidence policy
- missing certification history

Health statuses:
- HEALTHY
- WATCH
- DEGRADED

Snapshots are persisted for trend/history analysis.

Workspace:
`/app/settings/platform-readiness/ai-runtime-health`

API:
- `GET /api/platform/ai-runtime-health`
- `POST /api/platform/ai-runtime-health`

Migration:
`20260809060000_ai_runtime_health_monitoring`

B13.2 is observational only.
It does not:
- change policies
- change runtime adoption modes
- retrain models
- alter predictions/recommendations
- trigger procurement execution
