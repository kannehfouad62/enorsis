# B13.10.5a — Typecheck and Prisma Index Drift Hotfix

This hotfix corrects issues found by local TypeScript and Prisma validation after
B13.10.5 was applied.

Corrections:
- notification priority uses Enorsis `URGENT` instead of unsupported `CRITICAL`
- seller notification roles are typed as generated `PlatformRole[]`
- marketplace checkout follows the current catalog data-access pattern:
  offerings, suppliers and media are queried separately because the Prisma
  offering model does not expose `supplier` or `media` relation includes
- explicit short Prisma index mappings avoid PostgreSQL identifier truncation
- the migration renames the three already-created indexes to those mapped names

No procurement workflow behavior is removed or simplified.
