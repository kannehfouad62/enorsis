# B13.10.6 — Pre-Activation Tenant Role Assignment

Platform Super Admin can assign one or more tenant-scoped roles to a member
before sending the user's activation invitation.

Workflow:
1. Open Platform Tenant Administration.
2. Open a tenant.
3. Locate the member.
4. Select one or more tenant access roles.
5. Save assigned roles.
6. Send or resend the activation invitation.
7. User creates credentials and logs in with the already-provisioned roles.

Activation is blocked when a non-owner member has no assigned role.

Platform-only roles remain unavailable through this tenant-member control:
PLATFORM_SUPER_ADMIN and PLATFORM_SUPPORT.

Tenant Owner membership remains managed through the dedicated Tenant Owner
controls.

Role changes are written to AuditEvent.

No Prisma migration is required.
