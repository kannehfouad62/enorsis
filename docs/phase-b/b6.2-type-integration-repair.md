# B6.2 Type Integration Repair

Fixes two existing-schema compatibility issues:

1. `SupplierPortalInvitation.supplierId` is nullable. Supplier self-service now
   explicitly rejects any invitation that is not bound to a supplier before
   querying supplier or portal-user data.

2. `AuditActorType` does not contain `EXTERNAL`. Supplier self-service audit
   events use the existing `USER` actor type while preserving the external
   supplier portal user ID and email in `actorId` and `actorLabel`.

No Prisma migration is required.
