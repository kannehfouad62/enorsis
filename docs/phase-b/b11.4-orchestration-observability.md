# B11.4 — Orchestration Observability, Run Trace & Operational Metrics

B11.4 completes the B11 orchestration layer with read-only operational
observability.

No new database model is required. It derives metrics from the existing:

- AutonomousProcurementOrchestrationRun
- AutonomousProcurementOrchestrationEvent
- AutonomousProcurementOrchestrationEscalation
- AutonomousProcurementOrchestrationSignal

Metrics include:
- total / active / paused / completed / failed runs
- completion rate
- failure rate
- average end-to-end cycle time
- P95 end-to-end cycle time
- stage distribution
- workflow completion distribution
- open and critical escalations
- event distribution
- resume signal processing success
- ignored signal pressure
- recent run event traces

Workspace:
`/app/automation/orchestrator/observability`

Metrics API:
`/api/automation/autonomous-orchestration/observability`

B11.4 is read-only. It does not:
- advance orchestration
- release execution
- activate adapters
- resolve escalations
- post inventory
- submit purchase requests
- publish sourcing events
- validate savings
- activate resilience plans

No Prisma migration is required.
