# B11.2 — Orchestration SLA, Escalation & Recovery

B11.2 adds operational governance to the B11.1 autonomous procurement
orchestration runtime.

SLA rules:
- PAUSED at human gate for 24h -> HUMAN_GATE_AGING / HIGH
- READY or RUNNING without progress for 60m -> EXECUTION_STUCK / HIGH
- RETRY aging for 4h -> RETRY_AGING / HIGH
- FAILED -> TERMINAL_FAILURE / CRITICAL

Escalations are durable records with:
- type
- severity
- status
- stage/run status
- age and threshold
- evidence
- occurrence count
- acknowledgement
- resolution

Recovery:
- only FAILED or RETRY runs can be manually reset to READY
- recovery records an orchestration event
- active escalation records are resolved with the recovery actor
- recovery does not synthesize missing human approvals or native workflow acts
