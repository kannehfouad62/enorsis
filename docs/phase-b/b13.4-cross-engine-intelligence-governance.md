# B13.4 — Cross-Engine Intelligence Governance

B13.4 reconciles the latest predictive procurement, inventory and capacity
intelligence before high-impact operational action.

Conflict classes:

1. CAPACITY_VS_REPLENISHMENT
   - urgent reorder/replenishment exists
   - enterprise capacity is HIGH or CRITICAL
   - precedence: capacity guardrail before replenishment

2. DEMAND_GROWTH_VS_CAPACITY
   - elevated procurement demand/spend growth exists
   - enterprise capacity is HIGH or CRITICAL
   - precedence: joint demand/capacity review

3. SUPPLIER_RISK_VS_REPLENISHMENT
   - elevated supplier-risk forecast exists
   - urgent replenishment exists
   - precedence: supplier-risk review before commitment

4. MULTI_ENGINE_CRITICAL_ESCALATION
   - two or more engines report CRITICAL conditions
   - precedence: executive multi-engine review

The assessment stores:
- latest run IDs
- conflict counts
- severity counts
- alignment score
- evidence snapshot

Each conflict stores:
- conflict type
- severity
- scope
- rationale
- precedence rule
- recommended governance action
- evidence
- human resolution record

Workspace:
`/app/settings/platform-readiness/cross-engine-governance`

API:
`POST /api/platform/cross-engine-governance`

Migration:
`20260809070000_cross_engine_intelligence_governance`

B13.4 is governance-only. It does not execute procurement, inventory or
capacity transactions.
