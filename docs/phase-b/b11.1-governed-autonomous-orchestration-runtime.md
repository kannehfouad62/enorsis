# B11.1 — Governed Autonomous Procurement Orchestration Runtime

B11.1 coordinates the completed B9/B10 execution chain.

It discovers only `READY_FOR_HANDOFF` records that already originate from a
human-released execution envelope.

State path:

RELEASED_HANDOFF
→ ADAPTER_PREPARED
→ [PAUSE: operator activation required]
→ NATIVE_DRAFT_MATERIALIZED
→ NATIVE_RECORD_CREATED
→ COMPLETED

Controls:
- human release is never synthesized
- adapter activation is never synthesized
- paused runs resume only after the corresponding human gate exists
- native B10 adapters create draft/qualifying records only
- native submission, posting, award, activation and finance validation remain
  outside autonomous control
- idempotency is anchored by unique tenant + executionHandoffId
- retry is capped at 8 attempts with 15-minute retry scheduling
- every transition and wait state is recorded as an orchestration event

The runtime reuses the existing Enorsis `CRON_SECRET` authorization pattern.
