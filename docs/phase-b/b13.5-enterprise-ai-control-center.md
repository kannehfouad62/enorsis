# B13.5 — Enterprise AI Control Center

B13.5 consolidates Enorsis AI governance and runtime posture into one
administrative workspace.

Control Center surfaces:
- B13.1 certification status and score
- B13.2 runtime health and score
- B13.3 engine OFF / SHADOW / ENFORCED modes
- ACTIVE governed learning policies
- runtime-supported policy count
- latest promotion readiness
- latest cross-engine alignment assessment
- open cross-engine governance conflicts
- recent runtime decision traces
- AI provider configuration presence

Provider configuration is presence-only:
- OpenAI
- Azure OpenAI
- Anthropic
- Google Generative AI

No secret value is displayed or returned.

Governance readiness requires:
- latest AI runtime certification = PASSED
- current runtime health = HEALTHY
- zero open cross-engine governance conflicts

Workspace:
`/app/settings/platform-readiness/ai-control-center`

API:
`GET /api/platform/ai-control-center`

No Prisma migration is required. B13.5 aggregates existing governed state.

B13.5 does not:
- expose API keys
- modify policies
- promote runtime modes
- resolve conflicts automatically
- execute procurement actions
