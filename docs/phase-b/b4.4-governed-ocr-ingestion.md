# B4.4 — Governed OCR Ingestion

Adds explicit OCR ingestion for:
- scanned PDF
- PNG
- JPEG

The OCR path:
- uses tenant-authorized private Vercel Blob reads
- uses the existing OpenAI client and configured model
- instructs the model to transcribe rather than summarize
- preserves document/source metadata
- indexes extracted text through the B4.2 embedding pipeline
- writes an AuditEvent
- keeps OCR opt-in rather than automatic

Optional environment:
`OPENAI_OCR_MODEL`

If omitted, Enorsis uses `OPENAI_MODEL`, then `gpt-5`.

No Prisma migration is required.
