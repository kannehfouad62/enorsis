# B9.4 — Controlled Transaction Adapter Queue

B9.4 introduces the idempotent bridge between released B9.3 controlled
execution handoffs and native Enorsis workflows.

Supported workflow adapters:
- PURCHASE_REQUEST -> /app/requisition-to-order/purchase-request
- STRATEGIC_SOURCING -> /app/sourcing
- INVENTORY_REBALANCE -> /app/inventory-operations
- RISK_MITIGATION -> /app/resilience
- VALUE_REALIZATION -> /app/value-realization
- GOVERNED_REVIEW -> /app/reviews

Controls:
- one adapter job per released handoff
- deterministic idempotency key
- immutable staged draft payload
- operator activation required
- native approval bypass is explicitly false
- audit events for preparation, activation and cancellation

Important:
B9.4 deliberately does not guess or bypass native transaction creation
contracts. It prepares a governed draft handoff and routes the operator into
the existing native workflow. This preserves existing validation, approval,
audit and SLA behavior.
