# B9.1 Enterprise Modules Group Repair

The B9.1 module was initially registered with:

`group: "Automation"`

The current `EnterpriseModuleLink` type only permits:

- Governance
- Suppliers
- Platform
- Procurement
- Intelligence

Rather than expanding the global navigation taxonomy for a single module,
B9.1 is placed under `Intelligence`.

This is appropriate because Autonomous Procurement Planning is an
AI/predictive orchestration capability. Its route remains:

`/app/automation/autonomous-planning`

No database, schema, authorization, planning-engine, or workflow behavior is
changed.
