# B8.1 Prisma Integration Repair

This repair addresses the two remaining B8.1 integration items.

## Prisma JSON input typing

`PredictiveProcurementForecastSignal.evidence` is a required Prisma Json field.
The forecast engine originally declared the in-memory signal payload as
`Record<string, unknown>`, which is broader than Prisma's accepted JSON input
type.

The repair imports the Prisma namespace from the application's generated client:

`@/generated/prisma/client`

and types evidence as:

`Prisma.InputJsonValue`

No unsafe cast is used and the forecasting algorithm is unchanged.

## Index normalization

Prisma requested one PostgreSQL index rename after the primary B8.1 migration.
The included migration performs that rename only.

Migration:
`20260808111500_b8_1_normalize_forecast_index_name`
