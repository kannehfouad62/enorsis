# B7.4 — Governed AI Supplier Matching

Completes the B7 Procurement Marketplace intelligence layer.

Deterministic supplier ranking:
- capability/category fit
- geographic fit
- marketplace trust
- supplier performance
- risk posture
- catalog availability
- optional mandatory marketplace verification
- optional certification, currency and lead-time constraints

Governed AI:
- uses existing `SUPPLIER_ANALYSIS` capability
- AI receives only the deterministic shortlist/evidence
- AI cannot alter the numeric ranking
- AI cannot approve or select a supplier
- existing AI execution logging, confidence and human review controls apply
- deterministic result persists even if AI is unavailable

Persistence:
- match run
- requirement and constraints
- score weights
- ranked supplier results
- evidence per result
- governed AI execution reference and narrative
