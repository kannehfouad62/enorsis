# B13.7 — Security & Governance Certification

B13.7 provides formal, persisted certification of security and governance
invariants around the governed AI runtime.

Scenarios:
1. Tenant-scoped governance reads
2. Human activation evidence for ACTIVE policies
3. No direct OFF -> ENFORCED adoption transition evidence
4. Runtime trace policy provenance consistency
5. AI provider secret non-disclosure
6. Automatic rollback governance
7. Cross-engine conflict resolution audit evidence
8. Required certification chain presence

The suite is observational and non-destructive.

It does not:
- create users
- elevate roles
- modify RBAC
- rotate secrets
- reveal API key values
- change policies
- change runtime modes
- execute procurement work

Workspace:
`/app/settings/platform-readiness/security-certification`

API:
`POST /api/platform/security-certification`
