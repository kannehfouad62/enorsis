# B8.2 Authorization Repair v2

The first repair script used an exact multiline string match and could fail when
the locally formatted `actions.ts` role array differed in whitespace or ordering.

This v2 repair is format-independent:

- locates the `const roles = [...] as const` array using a regular expression
- removes `INVENTORY_MANAGER` wherever it appears
- removes `WAREHOUSE_MANAGER` wherever it appears
- ensures `RISK_COMPLIANCE` is present
- ensures `SUPPLIER_MANAGER` is present
- does not change B8.2 forecasting or inventory logic

The previously added index-normalization migration remains valid and should be
run after this script.
