# B7.2 — Product Catalog & Supplier Offerings

Adds a marketplace product/service listing layer without replacing guided buying.

Capabilities:
- product and service listings
- optional SKU/service code
- category/subcategory
- manufacturer, brand, model
- unit of measure
- currency and unit price
- minimum order quantity
- lead time
- availability status
- countries available
- certifications
- keywords
- image/document/external references
- marketplace visibility
- featured listings
- buyer search across supplier + offering metadata

Route:
`/app/marketplace/catalog`
