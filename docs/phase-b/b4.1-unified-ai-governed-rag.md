# B4.1 — Unified Procurement AI + Governed Retrieval Foundation

This phase creates the first unified, tenant-grounded Procurement AI workspace.

Knowledge sources:
- enterprise contract metadata and summaries
- supplier master data
- enterprise policy definitions and tenant overrides
- configured workflow procedures

Governance:
- reuses `executeGovernedAi`
- persists all executions in `AiExecution`
- retains prompt versioning, review state, confidence and token usage
- persists retrieved source references into execution evidence
- does not execute controlled procurement actions
- requires human approval for controlled decisions

Architecture note:
B4.1 intentionally does not introduce a second vector database. It provides
deterministic structured retrieval over existing tenant records first.

B4.2 will add private document ingestion, extracted text/chunking, embeddings,
semantic retrieval and knowledge-source lifecycle governance for supplier
documents, contract files, internal procedures and company knowledge.

No Prisma migration is required for B4.1.
