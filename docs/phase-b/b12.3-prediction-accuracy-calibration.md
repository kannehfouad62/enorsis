# B12.3 — Prediction Accuracy, Calibration & Recommendation Effectiveness

B12.3 aggregates only validated closed-loop outcomes.

Metrics:
- validated outcomes
- validated predicted/actual metrics
- mean absolute percentage error (MAPE)
- median absolute percentage error
- P95 absolute percentage error
- mean absolute error
- recommendation effectiveness for BOOLEAN outcome indicators
- workflow-level effectiveness
- metric-level accuracy
- confidence calibration buckets

Confidence calibration compares average model confidence to observed accuracy.
The calibration gap helps identify over-confidence and under-confidence.

Workspace:
`/app/analytics/outcome-learning/calibration`

API:
`/api/analytics/outcome-learning/calibration`

No Prisma migration is required.

B12.3 is analytical only and does not:
- retrain models
- change confidence thresholds
- change recommendation logic
- modify autonomous execution policies
