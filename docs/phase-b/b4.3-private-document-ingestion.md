# B4.3 — Private Document Ingestion & Extraction

Adds server-side document extraction and indexing for existing private Enorsis
supplier and contract documents.

Supported:
- text-based PDF
- DOCX

Pipeline:
1. authorize tenant user
2. resolve document through tenant-scoped Prisma query
3. read the existing private Vercel Blob server-side
4. extract text
5. create or update an EnterpriseKnowledgeSource
6. chunk and embed through B4.2
7. preserve originating document, supplier/contract, blob path, content type,
   extraction method and byte count as source metadata
8. record audit evidence

Scanned PDFs, PNG and JPEG are not automatically indexed in B4.3. They require
the separate OCR ingestion sub-block.

Dependencies:
- pdf-parse
- mammoth

No Prisma migration is required because B4.3 reuses the B4.2 knowledge models.
