# B7.1 — Supplier Discovery & Global Search

Adds an additive marketplace discovery layer on top of the existing supplier
master.

Marketplace profile capabilities:
- marketplace visibility
- verification status
- headline and description
- website and headquarters country
- countries served
- industries
- procurement categories
- supplier capabilities
- certifications
- search keywords
- preferred currency
- lead time
- employee and revenue bands
- sustainability and diversity tags
- quality/risk/performance/marketplace scores

Search:
- supplier/legal/trading name
- supplier number
- country
- industry
- category
- capabilities
- keywords
- verification status

The Supplier model remains the system of record. Marketplace metadata is keyed
by tenantId + supplierId.

Route:
`/app/marketplace/suppliers`

Migration:
`20260808070000_supplier_marketplace_discovery`
