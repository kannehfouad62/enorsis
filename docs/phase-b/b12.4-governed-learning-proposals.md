# B12.4 — Governed Learning Recommendations & Calibration Proposals

B12.4 converts validated B12.3 analytics into explicit governance proposals.

Proposal types:
- CONFIDENCE_THRESHOLD
- PREDICTION_RULE_REVIEW
- WORKFLOW_RECOMMENDATION_REVIEW

Generation rules are intentionally conservative:
- confidence buckets require at least 5 samples
- calibration gap must be at least 10 percentage points
- prediction-rule review requires at least 5 observations and >=25% MAPE
- workflow recommendation review requires at least 5 outcomes and <60%
  recommendation effectiveness

Each proposal records:
- scope
- rationale
- current value
- proposed value where applicable
- proposal confidence
- evidence count
- evidence snapshot
- human review decision

A proposal can be APPROVED or REJECTED.

Approval does not apply the change.

Workspace:
`/app/analytics/outcome-learning/proposals`

Generation API:
`POST /api/analytics/outcome-learning/proposals/generate`

Migration:
`20260809000000_closed_loop_learning_proposals`

Prisma workflow:
`npx prisma format`
`npx prisma generate`
`npx prisma migrate deploy`
