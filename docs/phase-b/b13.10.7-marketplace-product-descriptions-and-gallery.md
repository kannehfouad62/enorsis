# B13.10.7 — Marketplace Product Descriptions & Photo Gallery

## Purpose

Improve Buyer marketplace product evaluation without turning the catalog into a
dense product-detail page.

## Product card presentation

Each marketplace product/service family displays:

- primary product photo
- previous/next photo controls when multiple photos exist
- current photo counter
- thumbnail strip
- product/service name
- model when present
- short description
- expandable full description
- pricing, lead-time and supplier comparison data

## Gallery behavior

MarketplaceProductGallery is a small client component embedded in the existing
server-rendered MarketplaceComparisonResults component.

The gallery receives the already-loaded private marketplace media metadata and
uses the existing authenticated media endpoint for image rendering.

Single image:
- no arrows
- no redundant counter
- no thumbnail strip

Multiple images:
- circular previous/next navigation
- thumbnail selection
- `current / total` counter

No images:
- existing marketplace placeholder remains visible.

## Data model

No schema change is required. The feature reuses:

- SupplierMarketplaceOffering.shortDescription
- SupplierMarketplaceOffering.description
- SupplierMarketplaceOfferingMedia

No Prisma migration is required.
