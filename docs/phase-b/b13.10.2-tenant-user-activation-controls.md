# B13.10.2 — Tenant User Activation Controls

Adds Platform Super Admin controls to trigger or retrigger secure activation for any passwordless user already attached to a tenant.

Tenant page:
/app/settings/tenants/[id]

Each member shows:
- user name/email
- assigned roles
- membership status
- credential status
- Send activation invitation
- Resend activation invitation

Users with an existing password do not receive an activation button.

Activation link:
/activate-user-account?tenant=<tenantId>&token=<single-use-token>

No user or tenant recreation is required.
