# B12.2 — Automatic Native Outcome Reconciliation

B12.2 automatically observes facts from the native Enorsis record linked to a
B12.1 closed-loop outcome.

Supported native workflows:

## Purchase Request
Observes:
- native PR exists
- native USD total
- approved/not approved

## Strategic Sourcing
Observes:
- sourcing event exists
- sourcing event reached AWARDED/CLOSED
- native estimated value when present

## Risk / Resilience
Observes:
- resilience plan exists
- plan reached ACTIVATED/COMPLETED

## Value Realization
Observes:
- initiative exists
- realizedBenefitAmount

## Inventory Rebalancing
Observes:
- transfer draft exists
- transfer posted/not posted
- native transfer quantity

Important:
B12.2 records transactional facts only.

It does not infer:
- savings from PR approval
- sourcing success from award status
- risk reduction from plan activation
- inventory optimization value from transfer posting

These interpretations remain subject to outcome validation.

Processor:
`/api/analytics/outcome-learning/reconciliation/process`

Workspace:
`/app/analytics/outcome-learning/reconciliation`

No Prisma migration is required. B12.2 uses the B12.1 outcome models and
existing native transactional models.
