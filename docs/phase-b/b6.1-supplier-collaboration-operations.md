# B6.1 — Supplier Collaboration Operations

Extends the existing Supplier Portal & Onboarding foundation.

Adds:
- supplier invoice submission records
- supplier shipment update records
- buyer–supplier conversation threads
- persistent messages
- PO/context references
- audit events for invoice and shipment submissions
- Suppliers-group Enterprise Module registration
- Supplier Portal licensing metadata

Architecture:
The existing Invoice, LogisticsShipment, SupplierPortalTask, onboarding and
sourcing systems remain unchanged. B6.1 is the collaboration intake layer.

B6.2 will add authenticated supplier self-service flows that allow external
supplier portal users to submit invoices, shipment updates and messages
directly into these records.
