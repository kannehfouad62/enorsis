# B13.10.17a — Marketplace Media Server Action Button Fix

React does not permit `name` or `value` on a button whose `formAction` is a
function Server Action because React reserves those fields to encode the action.

The seller catalog previously used:

- function `formAction`
- `name="mediaId"`
- `value={item.id}`

for both Make Primary and Remove.

The listing card is already inside another `<form>`, so introducing nested forms
would be invalid.

This hotfix binds `item.id` directly into each Server Action:

`action.bind(null, item.id)`

and updates the server functions to receive:

`mediaId: string, _data: FormData`

No behavior or authorization changes.
No Prisma migration.
