# B13.10.14 — Receipt-Driven Finance Automation & Vendor-First Marketplace

When a PO becomes fully received, Enorsis now advances existing finance records automatically.

If a linked supplier invoice exists, Enorsis runs the existing three-way match with zero tolerance. Exact matches move directly to `MATCHED` and `PAYMENT_READY`; exceptions remain blocked for AP review.

If no invoice exists, Enorsis does not fabricate one. Accounts Payable / Finance receives an in-app and email notification that receipt is complete and invoice capture is required.

For the governed Requisition-to-Order path, fully accepted goods receipts automatically approve already-matched ThreeWayMatchCases for payment and automatically approve existing READY payment-readiness cases when no active hold or blocking failed check exists.

Purchase Orders remain an upstream control created after Purchase Request approval. Receipt does not create a duplicate PO.

The Buyer Marketplace Catalog now lands on a vendor directory. Buyers select a supplier first, then see that supplier's products/services. Vendor cards show name, supplier number, location, shipping coverage, offering count and categories. Supplier tenants retain their existing listing-management view.

No Prisma migration is required.
