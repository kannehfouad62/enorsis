# B9.3 Prisma JSON Typing Repair

The database stores `AutonomousExecutionEnvelope.executionPayload` as Prisma
`JsonValue` when read. Creating `AutonomousExecutionHandoff` expects
`Prisma.InputJsonValue`.

The repair converts the persisted JSON value through JSON serialization before
passing it into the create input and explicitly types the result as
`Prisma.InputJsonValue`.

This is a TypeScript/Prisma input typing repair only.

No schema, migration, policy, approval, execution-envelope, or handoff behavior
is changed.
