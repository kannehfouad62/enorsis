# B13.10.4B — Global Link/Button Contrast & Unauthorized UX

## Root cause

Enorsis imports Tailwind CSS and then declares an unlayered global rule:

`a { color: inherit; text-decoration: none; }`

Tailwind v4 utilities are emitted inside cascade layers. A normal unlayered
author rule can outrank layered utility declarations such as `text-white`.
As a result, Link components styled as dark buttons can render a dark
background while inheriting dark surrounding text, making their labels appear
covered or invisible.

## Fix

Move global anchor/button defaults into Tailwind's `base` layer:

`@layer base { ... }`

This preserves neutral anchor defaults while allowing utility classes such as:

- `text-white`
- `text-blue-700`
- hover/focus foreground utilities

to win as intended.

The unauthorized page CTA is also hardened with:

- explicit white foreground
- visible hover state
- keyboard focus ring
- icon + text layout

## Scope

This is a global visual-system correction and should improve Link-based buttons
throughout Enorsis, not only `/app/unauthorized`.

It does not alter authorization, tenant persona guards, routes, permissions or
commerce behavior.
