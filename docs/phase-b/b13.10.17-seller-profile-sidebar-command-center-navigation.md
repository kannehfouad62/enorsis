# B13.10.17 — Seller Profile Sidebar & Command Center Navigation

## Problem

The logged-in tenant identity block in the AppShell sidebar was rendered as a
plain `<button>` with no `onClick`, route or menu behavior.

Users naturally interpreted the tenant identity card as a profile entry point,
but clicking it performed no action.

## Sidebar tenant identity

For commercial personas:

- SUPPLIER
- BUYER_SUPPLIER

the tenant identity block now links directly to:

`/app/marketplace/seller-profile`

The block visibly shows:

`Open seller profile`

and includes hover/focus feedback.

For non-seller personas, the same tenant identity block links to:

`/app/settings/organization`

so it is no longer a dead control.

## Sidebar navigation

A dedicated:

`Seller profile`

workspace navigation item is added for seller-capable tenants and appropriate
roles.

## Supplier Command Center

A new first-class workspace card is added:

`Seller Business Profile`

It opens:

`/app/marketplace/seller-profile`

and describes management of:
- marketplace logo
- trading/business name
- website
- business contact details
- business categories

## Result

Supplier users now have three explicit ways to reach Seller Profile:

1. Sidebar tenant identity block
2. Sidebar `Seller profile` navigation item
3. Supplier Command Center `Seller Business Profile` workspace card

No Prisma migration is required.
