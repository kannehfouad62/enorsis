# B13.10.11 — Global Interactive Cursor & Action Affordance

## Purpose

Make actionable Enorsis controls immediately recognizable across the public site
and authenticated enterprise application.

## Pointer cursor

The browser pointer/hand cursor is now used for:

- hyperlinks
- enabled buttons
- expandable `<summary>` controls
- enabled select controls
- button/submit/reset inputs
- checkboxes and radio buttons
- elements explicitly using `role="button"`
- elements explicitly using `role="link"`
- future controls marked `data-clickable="true"`
- labels wrapping interactive checkbox/radio controls

## Disabled state

Disabled controls use the `not-allowed` cursor and reduced opacity.

## Visual feedback

Actionable links/buttons receive:

- subtle hover opacity feedback
- active/pressed movement
- short consistent transitions

This supplements existing component-specific hover styles rather than replacing
them.

## Keyboard accessibility

Interactive elements receive a visible `focus-visible` outline so keyboard users
can see the currently actionable control.

## Scope

This is a global presentation/UX change in `src/app/globals.css`.

No Prisma migration is required.
No application workflow behavior changes.
