# B8.3 — Predictive Capacity Planning

Extends B8.2 predictive inventory optimization with location-level capacity
pressure planning.

Current capability:
- active inventory-location planning
- current inventory units
- projected demand units
- projected inbound/reorder units
- projected ending inventory
- configurable target headroom
- operating capacity proxy
- projected utilization
- capacity gap
- pressure score
- risk classification
- rebalancing/capacity recommendations
- enterprise rollup
- persisted runs and signals
- audit logging

Important limitation:
The current Enorsis inventory master does not expose dependable physical
cubic-volume, weight, pallet-position or dock-capacity attributes through the
existing inventory workspace. B8.3 therefore uses an explicit inventory-unit
operating capacity proxy. This avoids pretending unit count equals physical
warehouse capacity.

Future warehouse-master-data enhancement can replace/enrich the proxy with:
- cubic capacity
- weight capacity
- pallet positions
- bin capacity
- dock throughput
- labor capacity
