# B13.10.19 — Hide Seller Profile from Platform Admin

The AppShell sidebar previously evaluated `isPlatformOperator` before the
`sellerOnly` restriction. This allowed Platform Super Admin users to see the
Seller Profile navigation entry even though the destination correctly denied
access.

Seller Profile is now visible only when:

- the user is NOT a platform operator, and
- the tenant persona is SUPPLIER or BUYER_SUPPLIER.

The sidebar tenant identity block follows the same rule.

Result:
- Platform Super Admin: hidden
- Platform Support/Auditor: hidden
- Supplier tenant: visible when role permits
- Buyer+Supplier tenant: visible when role permits
- Buyer-only tenant: hidden

The Seller Profile server-side authorization remains unchanged.

No Prisma migration is required.
