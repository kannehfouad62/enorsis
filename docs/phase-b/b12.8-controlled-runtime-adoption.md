# B12.8 — Controlled Runtime Adoption & Shadow Mode

B12.8 introduces a controlled adoption gateway for learning-policy influence.

Initial allowlisted decision path:
- PREDICTIVE_PROCUREMENT_CONFIDENCE

Modes:

OFF
- existing default threshold is authoritative
- governed threshold may be resolved/traced but cannot change the decision

SHADOW
- existing default threshold remains authoritative
- governed threshold is calculated
- default and governed decisions are compared
- differences are counted and traced

ENFORCED
- governed threshold becomes authoritative
- policy resolution remains bounded by B12.6
- every decision remains traceable through B12.7

Safety:
- direct OFF -> ENFORCED transition is blocked
- only the allowlisted predictive procurement confidence path is supported
- no procurement execution occurs here
- unsupported decision paths are rejected
- rollback to OFF or SHADOW is explicit and immediate

Primary runtime API:
`evaluateControlledRuntimeConfidence`

Workspace:
`/app/analytics/outcome-learning/runtime-adoption`

Migration:
`20260809030000_runtime_policy_adoption`

Important:
The gateway is intentionally created before modifying the predictive engine.
The exact local confidence decision point should be identified before wiring
the engine to this function.
