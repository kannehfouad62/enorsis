# B12.1 — Closed-Loop Outcome Capture & Learning Foundation

B12.1 begins the closed-loop learning layer.

It creates one governed outcome case per completed autonomous orchestration run
with a bound native Enorsis reference.

Outcome cases preserve:
- orchestration run
- execution handoff
- target workflow
- native record reference
- source confidence
- immutable source snapshot
- observation status
- validation status and actor

Outcome metrics preserve:
- metric key / label / unit
- predicted value
- observed actual value
- variance
- variance percentage
- confidence
- observation evidence
- observation actor/time
- validation state

Initial metric seeds are derived conservatively from the governed execution
payload:
- proposed value
- expected savings
- expected exposure
- proposed quantity
- native workflow completion indicators

B12.1 does not retrain models or automatically change AI behavior.

Only validated outcome observations should become eligible for future
calibration and learning.
