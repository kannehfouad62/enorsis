# B13.10.4C — Supplier Self-Identity & Persona-Aware Marketplace Navigation

Supplier and Buyer + Supplier tenants now publish through an automatically
resolved tenant self-supplier profile instead of selecting an ordinary Supplier
master record.

The self profile is marked `isTenantSelfProfile = true`, created automatically,
kept synchronized with tenant legal/trading identity, and audited.

Marketplace publishing no longer trusts a client-posted supplierId.

SUPPLIER tenants no longer see Buyer-only Marketplace header actions:
- Supplier Discovery
- Guided Buying

BUYER and BUYER_SUPPLIER tenants retain those Buyer-side actions.

Existing Supplier tenants do not need to be recreated. Their self supplier
identity is created automatically the next time Marketplace Catalog is opened.
