# B13.3 — Multi-Engine Controlled Adoption

B13.3 extends the governed runtime-adoption pattern to three intelligence
decision paths:

- PREDICTIVE_PROCUREMENT_CONFIDENCE
- PREDICTIVE_INVENTORY_CONFIDENCE
- PREDICTIVE_CAPACITY_CONFIDENCE

Each engine has an independent adoption row and mode.

Modes:

OFF
- existing engine output remains authoritative
- no governed threshold may suppress output

SHADOW
- governed confidence threshold is resolved and traced
- differences are recorded
- existing engine output remains authoritative

ENFORCED
- governed confidence threshold becomes authoritative
- candidate output may be suppressed
- B12.6 bounds and B12.7 traces remain active

Safety:
- direct OFF -> ENFORCED is blocked
- engines are independently governed
- unsupported decision paths are rejected
- no cross-engine global switch exists

Common runtime API:
`evaluateMultiEngineControlledConfidence(...)`

Workspace:
`/app/settings/platform-readiness/ai-engine-adoption`

No Prisma migration is required. B13.3 reuses the B12.8 adoption and event
tables.

Important:
This patch establishes the common control plane and runtime gateway. Predictive
inventory and predictive capacity engine files are intentionally not modified
until their exact local signal persistence/decision points are inspected.
