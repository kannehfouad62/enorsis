# B13.10.16a — Clickable Entire Seller Profile Card

The Seller Business Profile route already existed and the previous implementation
included an "Edit seller profile" button. However, the surrounding Marketplace
Seller Profile card remained a plain `<section>`.

This hotfix changes the entire card to a Next.js `Link` pointing to:

`/app/marketplace/seller-profile`

The logo, company name, descriptive text and action area are all clickable.

The card now also provides:
- pointer cursor through the global interactive affordance layer
- hover border/shadow feedback
- seller-name hover color
- keyboard focus ring
- "Click anywhere on this profile card to edit" guidance
- "Open seller profile →" visible action

No Prisma migration is required.
