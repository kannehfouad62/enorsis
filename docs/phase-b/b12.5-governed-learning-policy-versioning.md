# B12.5 — Governed Learning Policy Activation & Versioning

B12.5 turns approved B12.4 learning proposals into versioned governed policy
records.

Lifecycle:
APPROVED PROPOSAL
→ CANDIDATE POLICY
→ HUMAN ACTIVATION
→ ACTIVE POLICY
→ SUPERSEDED / ROLLED_BACK

Capabilities:
- one policy key per proposal type + scope
- monotonically increasing policy versions
- candidate materialization from approved proposals
- explicit privileged activation
- automatic supersession of prior active version
- rollback to the immediately available prior version
- immutable policy event history
- effective value captured separately from proposed/current value

Important:
B12.5 does not yet make the AI runtime consume the active policy.

It does not:
- alter forecasting models
- change prompt content
- change recommendation thresholds in runtime
- change autonomous execution policy
- retrain models

Workspace:
`/app/analytics/outcome-learning/policies`

Migration:
`20260809010000_closed_loop_learning_policy_versioning`

Prisma workflow:
`npx prisma format`
`npx prisma generate`
`npx prisma migrate deploy`
