# B11.1 Integration Repair

This repair addresses two integration issues found after B11.1 installation.

## Prisma JSON typing

`AutonomousProcurementOrchestrationEvent.evidence` is a Prisma Json field.
The orchestration helper previously supplied `Record<string, unknown>`, which
Prisma 7 does not accept directly as `InputJsonValue`.

The repair imports the generated Prisma namespace and casts the event evidence
to `Prisma.InputJsonValue`.

## Enterprise Module group typing

B11.1 introduced the `Automation` navigation group for the Autonomous
Procurement Orchestrator. The existing `EnterpriseModuleLink.group` union did
not yet include `Automation`.

The repair adds `Automation` as a first-class supported Enterprise Module group
instead of misclassifying the orchestrator under another group.

No schema changes.
No migration changes.
No database operations required.
