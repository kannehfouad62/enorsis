# B13.10.4A — Global Product Search & Multi-Supplier Comparison

Extends B13.10.4 with buyer-oriented global marketplace discovery.

## Buyer search

Searches all marketplace-visible supplier offerings across tenants.

Searchable data:
- product/service name
- supplier SKU
- category and subcategory
- brand
- manufacturer
- model number
- short/full description
- supplier legal/trading name
- supplier number
- keywords
- available countries
- certifications

Multiple search words are supported. Every entered word must appear somewhere
in the searchable offer/supplier text.

## Product-family grouping

Equivalent marketplace offers are grouped using:

1. brand/manufacturer + model number when model data exists; otherwise
2. normalized name + category + unit of measure.

Supplier-specific SKU is deliberately not the main family key because two
suppliers may use different internal SKUs for the same manufactured product.

## Comparison presentation

For each product family the Buyer sees:

- number of suppliers
- lowest listed price
- best stated lead time
- supplier
- price
- MOQ
- lead time
- availability
- supplier SKU

## Persona behavior

BUYER:
- global search and comparison
- no supplier catalog administration controls

SUPPLIER:
- manages its own offerings, including hidden drafts

BUYER_SUPPLIER:
- global search/comparison
- manages only its own supplier offerings

This block does not automatically create a Purchase Request line from a
marketplace offer. That binding should be implemented/certified separately so
the selected supplier, offer ID, price snapshot, currency and audit evidence are
preserved correctly.
