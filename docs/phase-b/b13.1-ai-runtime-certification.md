# B13.1 — Governed AI Runtime Certification & Safety Test Harness

B13.1 introduces formal, persisted, non-destructive AI runtime certification.

Certification scenarios:
1. Runtime adoption mode allowlist
2. One ACTIVE version per learning policy key
3. ACTIVE confidence-policy bounds
4. Confidence resolver boundary samples
5. Unsupported-policy safe fallback
6. Runtime decision-trace integrity
7. SHADOW legacy-behavior preservation
8. Promotion and rollback guardrail validity
9. Automatic rollback governance
10. Human activation audit evidence

Statuses:
- PASS
- WARN
- FAIL

Certification run statuses:
- PASSED
- PASSED_WITH_WARNINGS
- FAILED
- ERROR

Certification score:
- PASS = 1.0
- WARN = 0.5
- FAIL = 0.0

The harness is non-destructive:
- no policy promotion
- no runtime-mode changes
- no procurement execution
- no model retraining
- no automatic rollback

Only certification run and result records are persisted.

Workspace:
`/app/settings/platform-readiness/ai-runtime-certification`

API:
`POST /api/platform/ai-runtime-certification`

Migration:
`20260809050000_ai_runtime_certification`

Prisma workflow:

`npx prisma generate`
`npx prisma migrate deploy`
