# B12.7 — Governed Runtime Learning Observability & Decision Traceability

B12.7 adds durable audit traces for governed runtime policy decisions.

Trace data:
- decision type
- policy type/key/scope
- active policy ID
- proposal ID
- policy version
- ACTIVE_POLICY or DEFAULT source
- requested default
- effective value
- bounded value
- clamping flag
- input value
- decision result
- rationale
- optional actor
- optional correlation ID
- evidence snapshot

Primary traced runtime API:
`evaluateGovernedConfidenceGateWithTrace`

This wrapper uses the B12.6 confidence resolver and then records the exact
policy decision before returning the gate result.

Workspace:
`/app/analytics/outcome-learning/runtime-traces`

Read API:
`/api/analytics/outcome-learning/runtime-traces`

Migration:
`20260809020000_runtime_policy_decision_trace`

B12.7 does not:
- execute procurement actions
- mutate learning policies
- retrain models
- alter recommendations
- force existing callers to adopt tracing automatically

Runtime migration to the traced wrapper can therefore be gradual and explicit.
