# B4.2 — Enterprise RAG Semantic Knowledge

Adds the governed semantic knowledge layer for Enorsis AI.

Capabilities:
- tenant-isolated enterprise knowledge sources
- company knowledge
- procurement policies
- contract knowledge
- supplier-document knowledge references
- internal procedures
- deterministic text chunking
- OpenAI embeddings
- cosine-similarity semantic retrieval
- source enable/disable lifecycle
- source content hashing
- embedding model tracking
- AI execution evidence with source/chunk references
- audit logging for indexed sources
- Enterprise Modules registration under Intelligence

Storage:
Embeddings are persisted as Prisma JSON arrays in PostgreSQL. This deliberately
avoids adding pgvector or a second database during this phase. The retrieval
service reads a bounded chunk set and ranks it in the application layer.

Private binary document note:
Existing supplier documents remain private in Vercel Blob. B4.2 allows their
authoritative extracted/approved text and blob/record reference to be indexed.
Automated PDF/DOCX extraction is deferred to the next sub-block because the
current project has no approved text-extraction dependency.

Environment:
`OPENAI_EMBEDDING_MODEL` is optional and defaults to `text-embedding-3-small`.
