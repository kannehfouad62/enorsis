# B4.4 Generated Prisma Import Repair

Removes the invalid `@/generated/prisma` type import and replaces the OCR
metadata parameter with a JSON-safe primitive object type.

The current OCR metadata payload contains only strings, numbers, booleans and
null values, so no generated Prisma type import is required.

Run:
`node scripts/apply-b4.4-generated-prisma-import-fix.mjs`

No Prisma migration is required.
