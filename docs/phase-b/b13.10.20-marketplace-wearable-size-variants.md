# B13.10.20 — Marketplace Wearable Size Variants

## Goal

Allow suppliers to publish size availability for wearable products and require
buyers to select the required size before adding those products to a marketplace
Purchase Request.

This is not a new module. It extends the existing Supplier Marketplace,
Marketplace Cart, Purchase Request and governed order flow.

## Supplier experience

Publish Offering and Edit Offering gain an optional:

`Available sizes`

field.

Examples:

- Safety vest: XS, S, M, L, XL, 2XL, 3XL
- Gloves: 6, 7, 8, 9, 10, 11, 12
- Safety boots: US 7, US 8, US 9, US 10, US 11
- Uniforms: 30, 32, 34, 36, 38

Suppliers enter the sizes as comma-separated values.

Products/services without size variants leave this field empty and continue to
work exactly as before.

## Buyer experience

Marketplace search displays available sizes when configured.

The Add to Cart control shows a size selector before quantity.

If more than one size is available, the Buyer must choose a size.

The same offering can be added to the cart more than once with different sizes,
for example:

- Safety Vest · Size M · Qty 20
- Safety Vest · Size L · Qty 35
- Safety Vest · Size XL · Qty 15

These remain separate purchase lines.

## Server governance

The browser selection is not trusted.

At Purchase Request submission Enorsis reloads the marketplace offering and
checks:

- whether the offering requires a size
- whether a size was selected
- whether the selected size is still in the supplier's current available size list

Unavailable or stale size selections are rejected.

## Procurement continuity

The selected size is:

- shown in Marketplace Cart
- written into PurchaseRequestLine.description
- persisted on MarketplacePurchaseRequestLineBinding.selectedSize
- included in the Purchase Request audit event

Because the governed PO/order generation already consumes the Purchase Request
line description/binding, downstream users can see the required size during PO,
seller fulfillment and warehouse receiving.

## Schema

SupplierMarketplaceOffering:
- availableSizes String[]

MarketplacePurchaseRequestLineBinding:
- selectedSize String?
