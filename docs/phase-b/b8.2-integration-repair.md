# B8.2 Authorization & Index Integration Repair

This repair addresses the two remaining B8.2 validation issues.

## Authorization

The initial B8.2 action referenced `INVENTORY_MANAGER` and
`WAREHOUSE_MANAGER`, but those values are not part of the current
`EnorsisRole` union.

The repair preserves broad operational access using existing roles:

- TENANT_OWNER
- TENANT_ADMIN
- PROCUREMENT_EXECUTIVE
- PROCUREMENT_MANAGER
- BUYER
- FINANCE
- RISK_COMPLIANCE
- SUPPLIER_MANAGER

No global role-model changes are introduced.

## Prisma index normalization

The primary B8.2 migration applied successfully. Prisma subsequently requested
two PostgreSQL index-name normalizations. The included migration renames those
indexes only and does not change table structure or data.

Migration:
`20260808121500_b8_2_normalize_inventory_indexes`
