# B6.2 — External Supplier Self-Service

Adds a secure supplier-facing portal using the existing
SupplierPortalInvitation and SupplierPortalUser identity foundation.

Buyer administration:
- issue a 7-day random supplier portal token
- store only SHA-256 token hash
- scope access to tenant + supplier + invited email
- display the raw supplier URL once to the buyer for secure delivery

External supplier capabilities:
- submit invoices
- submit shipment updates
- start conversations
- reply to existing supplier-scoped conversations
- view supplier-assigned tasks
- view onboarding questionnaires
- view prior supplier submissions

Security:
Every supplier read/write resolves the invitation hash and expiration first,
then uses the invitation tenantId + supplierId + email for all downstream
queries. Suppliers cannot choose or override tenantId or supplierId.

External route:
`/supplier/portal/[token]`

Buyer administration route:
`/app/supplier-portal/access`

No Prisma migration is required; B6.2 reuses the existing Supplier Portal
identity models and B6.1 collaboration models.
