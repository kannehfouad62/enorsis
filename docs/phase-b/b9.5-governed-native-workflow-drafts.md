# B9.5 — Governed Native Workflow Draft Materialization

B9.5 advances B9.4 adapter jobs into governed native-workflow drafts.

This phase:
- accepts only OPERATOR_ACTIVATED B9.4 adapter jobs
- materializes one idempotent governed native draft per adapter job
- validates the native route and staged payload
- records workflow opening
- requires the resulting native Enorsis record ID/number to be bound back
- completes the B9.4 adapter job after native confirmation
- preserves native RBAC, approvals, validation, audit and SLA behavior

This phase does not directly insert native module rows or bypass native approvals.

Route:
`/app/governance/autonomous-execution/native-drafts`

Migration:

Prisma workflow:

`npx prisma migrate deploy`
