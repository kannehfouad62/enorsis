# B6.3 — Shared Documents & Supplier Action Requests

Completes the Supplier Collaboration Network foundation with:

- buyer-to-supplier shared document references
- supplier-to-buyer shared document references
- supplier acknowledgement status
- structured supplier action requests
- due date, priority and context references
- supplier responses and supporting document references
- buyer review, completion and reopening
- audit events for shared document exchange
- external supplier workspace at:
  `/supplier/portal/[token]/collaboration`
- buyer governance workspace at:
  `/app/supplier-portal/collaboration/requests`

This block stores governed document references rather than duplicating the
existing private document storage architecture.
