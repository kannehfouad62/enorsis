# B11.1 Integration Repair v2

This supersedes the first B11.1 integration repair script.

The original script assumed an exact formatting pattern for the
`EnterpriseModuleLink.group` union. The current Enorsis source formats that
declaration differently, so the exact string lookup failed before any files
were written.

v2:
- structurally locates the `EnterpriseModuleLink` type/interface
- locates its `group:` property independently of formatting
- appends `"Automation"` to the supported group union
- adds the generated Prisma namespace import when needed
- converts orchestration event evidence to `Prisma.InputJsonValue`

No Prisma schema change.
No migration.
No database operation.
