# Enorsis Procurement Savings and Value Realization

This module adds procurement value initiatives, baselines, targets, forecast
benefits, finance validation, realized value, leakage, one-time and recurring
benefits, evidence, milestones, blockers, and executive performance metrics.

Run:

```bash
python3 scripts/update-enterprise-modules-for-value-realization.py
```

to add the workspace to the Governance section of `/app/modules`.
