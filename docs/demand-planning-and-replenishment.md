# Enorsis Demand Planning and Replenishment

This module adds governed demand plans, item-level forecasts, safety-stock
coverage, available-inventory aggregation, lead-time-aware replenishment
recommendations, estimated order value, and approval controls.

Run:

```bash
python3 scripts/update-enterprise-modules-for-demand-planning.py
```

to add the workspace to the Procurement section of `/app/modules`.
