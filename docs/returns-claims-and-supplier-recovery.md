# Enorsis Returns, Claims and Supplier Recovery

This module adds post-delivery claims, warranty and freight cases, evidence,
supplier responses, return disposition, accepted and settled values, credit
notes, debit memos, refunds, replacements, and recovery tracking.

Run:

```bash
python3 scripts/update-enterprise-modules-for-claims.py
```

to add the workspace to the Procurement section of `/app/modules`.
