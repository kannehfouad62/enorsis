# Enorsis Sustainable Procurement and Responsible Sourcing

This module adds supplier ESG profiles, environmental, social and governance
scores, scope 1-3 emissions, renewable energy, waste and water indicators,
human-rights and modern-slavery declarations, diversity classifications,
responsible-sourcing assessments and supplier improvement plans.

Run:

```bash
python3 scripts/update-enterprise-modules-for-sustainability.py
```

to add the workspace to the Governance section of `/app/modules`.
